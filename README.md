# Zerodha Clone

This is a simple Zerodha trading dashboard clone made using React (frontend), Node.js + Express (backend), and MongoDB (database).

## Features
- Show Holdings
- Show Positions
- Show Orders
- Show Watchlist
- Portfolio summary & P/L calculation

## Tech Stack
- Frontend: React
- Backend: Node.js, Express.js
- Database: MongoDB (Mongoose)

## How to Run

### Backend
cd backend  
npm install  
npm start  

### Frontend
cd frontend  
npm install  
npm start  

## Usage
- Frontend runs on: http://localhost:3000
- Backend runs on: http://localhost:5000
